# 2026-07-16（Day 8）C1 开发日志

人员：C1

## 完成内容

### 1. 重试协调——参数保留

- `TaskSnapshot` 新增 `generation_params: dict` 字段，`create()` 时存入全部生成参数（instruction/attachments/num_pages/powerpoint_type/template/convert_type/enable_planner/language）
- `retry()` 不再硬编码 `attachments=[]`、`template=None`，改为从 `snapshot.generation_params` 恢复原始参数
- 重试时清空 `error_message`

### 2. 导出协调——文件存在性检查

- `export()` 增强：先检查 `result_artifact` 是否在磁盘上存在
- 不存在时扫描 `exports/` 目录，按修改时间排序取最新的 `.pptx`
- 仍找不到返回 None（前端收到 409）

### 3. 并发控制

- `TaskManager` 新增 `max_concurrent` 参数（默认 2），构造 `asyncio.Semaphore`
- `create()` 和 `retry()` 通过 `_runner_with_semaphore()` 包装，信号量耗尽时后续任务排队等待
- `app.py` 通过 `DEEPPRESENTER_MAX_CONCURRENT_TASKS` 环境变量配置，默认 2

### 4. 事件异常处理加固

- `EventReporter.emit()` 增加 try/except，发布失败只发 `RuntimeWarning`，不中断生成流程
- 避免 EventBus 关闭后或磁盘满时导致任务崩溃

### 5. Python 3.9 兼容修复

- C2 的 `preview.py` f-string 内含 `\"` 转义（3.12 特性），改为拼接字符串

### 6. 单元测试

新增 7 个测试用例：

- **参数保留**（3 个）：快照存储参数、retry 恢复参数、retry 清空错误信息
- **导出兜底**（2 个）：artifact 不在磁盘时扫描 fallback、无产物返回 None
- **并发限制**（2 个）：max_concurrent=1 排队正确、max_concurrent 配置生效
