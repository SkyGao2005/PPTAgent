## 完成内容

### 1. 模板模式任务衔接（Day 6）

#### PreviewService.render_template_slide()
- 新增方法：接收 slide_data（layout_name + StructuredContent），持久化 `mode="template"` 的 SlideArtifact
- 写入 `revisions/<n>/source.json`（结构化原始数据）和 `revisions/<n>/slide.json`
- 调用 `_write_index()` 更新 slides/index.json
- preview_path 暂为 None，PNG 渲染由 C2 后续补充

#### AgentEnv._maybe_capture_template_slide()
- 新增钩子，与已有的 `_maybe_render_html_preview()` 对称
- 触发条件：`generate_slide` 工具调用成功（非错误）
- 提取 slide_data → 调 PreviewService.render_template_slide() → 发 slide.preview_ready + slide.completed 事件
- 失败时发 slide.failed 事件（source_preserved=True）
- 在 `_report_tool_finished()` 中与 HTML 预览钩子并列调用

### 2. 取消检查点 + 重试 + 导出 + 恢复（Day 7）

#### _run_agent_loop 取消检查
- 在 `loop.run(request)` 的 async for 循环中检查 `cancel_evt.is_set()`
- 取消时发 task_cancelled 事件并立即返回，保留已完成产物

#### 每页 slide_ids 追踪
- TaskSnapshot 新增 `completed_slide_ids: list[str]` 字段
- to_dict()/from_dict() 支持序列化恢复
- 为重试时跳过已完成页面做准备

#### TaskManager.retry(task_id, retry_failed_slides_only)
- 仅 FAILED 状态可重试
- 重建 EventBus + EventReporter（若已关闭）
- 重新启动 `_run_agent_loop`，传递 retry_failed_slides_only 标记

#### TaskManager.export(task_id)
- 发送 export.started 事件
- 返回 result_artifact 或扫描 exports/ 目录
- 成功发 export.completed，失败发 export.failed

#### TaskManager.restore_snapshots(workspace_base) 类方法
- 扫描 workspace_base/ 下所有含 task.json 的子目录
- 加载 TaskSnapshot，重建 EventBus、EventReporter、PreviewService
- 孤儿 running 任务自动标记为 failed（error_message="服务异常重启"）

#### app.py 启动恢复
- 新增 `@app.on_event("startup")` 钩子
- 调用 `restore_snapshots()` 并将恢复的状态合并到当前 TaskManager
