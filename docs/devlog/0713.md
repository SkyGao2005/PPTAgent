# 2026-07-13（Day 1）C 方向开发日志

人员：C1、C2

## 完成内容

### 1. 接口契约（`docs/api-contract.md`）

冻结第一版四方接口文档，包含：

- 8 个 REST API 端点：任务 CRUD、SSE 订阅、幻灯片查询、产物读取、导出
- 24 种事件类型及字段定义
- 5 状态任务状态机（queued → running → completed/failed/cancelled）
- 6 阶段进度权重（prepare 5%、plan 10%、research 25%、generate 50%、export 10%）
- SSE 断线重连策略（seq 回放 + 去重）
- 9 个通用错误码
- SlideArtifact 数据模型与工作区目录结构

### 2. 事件模型（`deeppresenter/server/models/events.py`）

- `EventType`：24 种事件类型枚举，覆盖 task / template / stage / slide / edit / export
- `StageName`：6 阶段枚举及权重配置
- `TaskStatus`：5 状态枚举 + 合法转移校验函数
- `GenerationEvent`：13 字段 Pydantic 模型，支持 JSON 序列化/反序列化
- 进度计算：`stage_start_progress()` / `stage_end_progress()`
- JSONL 解析：`parse_events_from_jsonl()`，自动过滤心跳和 EOF 伪事件

### 3. 产物模型（`deeppresenter/server/models/artifacts.py`）

- `SlideArtifact`：页面持久化模型，含 slide_id / task_id / revision / structured_data 等字段
- `StructuredContent`：可编辑内容（标题、正文、图片、扩展元素）
- 工作区路径工具：`task_dir()` / `slide_dir()` / `revision_dir()` 等
- `is_path_safe()`：路径穿越防护
- `SlideArtifact.bumped()`：版本号自增
- 每页最多保留 10 个 revision

### 4. 事件总线（`deeppresenter/server/services/event_bus.py`）

- `EventBus`：进程内发布/订阅，基于 `asyncio.Queue`
- 发布自动分配递增 seq，写入 `events.jsonl`，广播至所有订阅者
- 支持多 SSE 订阅者、历史回放、30s 心跳
- 关闭哨兵机制，优雅退出不丢事件

### 5. 单元测试（39 个用例全部通过）

- `test_models.py`（25 个）：状态机、进度计算、事件序列化、JSONL 解析、SlideArtifact、路径安全
- `test_event_bus.py`（14 个）：发布/持久化/回放/多订阅者/心跳/生命周期

### 6. 事件样例（`docs/events-example.jsonl`）

一条完整任务的全部事件流（33 条），覆盖正常流程 + 单页失败 + 编辑穿插，前端可直接用于 mock 开发。

### 7. 兼容性修改

- `deeppresenter/__init__.py`：POSIX 断言增加 `DEEPPRESENTER_SKIP_POSIX` 环境变量开关，允许在 Windows 上运行不依赖运行时的模型测试
