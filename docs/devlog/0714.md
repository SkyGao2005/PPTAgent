# 2026-07-14（Day 2-3）C 方向开发日志

人员：C1、C2

## 完成内容

### 1. TaskManager（`deeppresenter/server/services/task_manager.py`）

实现任务生命周期管理，核心能力：

- **任务创建**：生成 8 位 hex task_id，初始化工作区、EventBus、取消信号，写入 `task.json` 初始快照，发出 `task.created` 事件，然后异步启动执行器
- **状态机**：严格遵循合法转移路径（queued→running→succeeded/failed/cancelled），终态不可逆。每次状态变更同时更新内存快照并落盘
- **快照持久化**：`TaskSnapshot` 类支持 to_dict/from_dict 双向转换，状态变更时写入 `workspace/<task_id>/task.json`
- **任务取消**：发送取消信号 → 取消 asyncio.Task → 关闭 EventBus。已完成页面保留，不启动新页
- **占位执行器**：模拟 prepare→plan→research→generate→export 五个阶段的推进，每阶段发出 started/completed 事件并更新进度。Day 4-5 将替换为真实 AgentLoop 回调
- **并发隔离**：不同任务使用独立工作区、EventBus 和取消信号，互不影响

### 2. FastAPI 路由（`deeppresenter/server/routes/tasks.py`）

实现了 `docs/api-contract.md` 中定义的 8 个 REST 端点中的核心部分：

| 端点 | 功能 |
|------|------|
| `POST /api/tasks` | 创建任务，返回 task_id |
| `GET /api/tasks` | 列出所有任务 |
| `GET /api/tasks/{task_id}` | 获取任务快照（状态、进度、阶段等） |
| `GET /api/tasks/{task_id}/events` | SSE 订阅，支持 last_seq 回放 |
| `POST /api/tasks/{task_id}/cancel` | 取消任务 |
| `GET /api/tasks/{task_id}/artifacts/{path}` | 产物文件读取，含路径穿越防护 |

SSE 响应设置 `Cache-Control: no-cache`、`X-Accel-Buffering: no` 等头确保实时推送不被缓冲。

### 3. FastAPI 入口（`deeppresenter/server/app.py`）

- `create_app(workspace_base)` 工厂函数，返回配置好的 FastAPI 实例
- 通过 `app.state.task_manager` 注入 TaskManager，路由通过 `Request.app.state` 获取
- 支持 `DEEPPRESENTER_WORKSPACE_BASE` 环境变量自定义工作区路径
- 附带 `/health` 健康检查端点
- 模块级 `app` 实例可直接 `uvicorn deeppresenter.server.app:app` 启动

### 4. 单元测试

新增 `test_task_manager.py`，含 15 个测试用例：

- **TaskSnapshot**（3 个）：默认值、序列化往返、字符串状态反序列化
- **任务创建**（4 个）：返回 task_id、发出 task.created 事件、快照落盘、占位执行器启动
- **任务查询**（2 个）：未知任务返回 None、列出全部任务
- **任务取消**（4 个）：取消运行中任务、取消不存在的任务、快照更新、占位执行器停止
- **并发**（2 个）：两个任务独立隔离、取消一个不影响另一个
